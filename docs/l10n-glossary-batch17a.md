# Localization glossary, batch 17 part A (Indic: mr ne sa kok mai brx doi as mni-Beng)

"Remindr" and "Remind UI" are never translated. "PIN", "OK", file names and `{0}` placeholders stay as written. Buttons use the polite imperative of each language, and wording is gender-neutral where the language allows it. Scripts: Devanagari for mr, ne, sa, kok, mai, brx, doi; Bengali-Assamese for as and mni-Beng.

Plurals (CLDR): mr, ne and brx use One (1) and Other; as and doi use One (0 and 1) and Other. sa, kok, mai and mni have no CLDR rule in the app, so they always use Other; their One and Other texts are written number-neutral so both read correctly. Every language also has the explicit Zero text.
