# Localization glossary, batch 16 part A (right-to-left): fa ur ps sd-Arab ug ckb pa-Arab ks-Arab dv

"Remindr" and "Remind UI" stay in Latin letters. "OK", "PIN", "Ctrl+N", "Esc", "GitHub", "PNG", "JPG" and file names stay as they are. Placeholders stay ASCII. No bidi control characters are used. Every language here has only the plural categories One and Other (plus the explicit Zero text), per `PluralRules.Generated.cs`; fa and pa count 0 as One.
