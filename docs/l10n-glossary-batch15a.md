# Localization glossary, Phase 4 batch 15 part A (Cyrillic-script languages)

Fixed terms for bg, mk, sr-Cyrl, be, kk, ky, tg, tt and ba. "Remindr" and "Remind UI" are never translated. PIN is written in Cyrillic as the language does it ("ПИН", Belarusian "ПІН"). All text is in Cyrillic script (Serbian is the sr-Cyrl culture). Tone: informal, calm and short, like the Russian and Ukrainian files.
