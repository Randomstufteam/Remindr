# Localization glossary, batch 17 part B (Indic, Sinhala, Ol Chiki)

"Remindr" and "Remind UI" are never translated. "PIN", "OK", "GitHub", "Windows", "PNG/JPG", "Ctrl+N", "Esc" and the file name error.log stay in Latin letters. Date patterns (Fmt_*) are copied from the Hindi file (day-first, `d MMM`).

Plural categories (CLDR, from PluralRules.Generated.cs): pa, gu, kn, si have One (0 and 1) and Other; or, ta, te, ml have One (1) and Other; sat has One, Two and Other. Every language also keeps the explicit `_Zero` "no items" text. sat additionally gets `_Two` keys.
